How to Read These Prices

Providers bill input tokens (what you send) and output tokens (what the model writes) separately, per million tokens. Output is usually several times more expensive. Context is the largest request the model accepts, in thousands of tokens. A typical English word is about 1.3 tokens.

Work out what it would cost youCost Forecaster turns these prices into a monthly estimate for a chatbot, agent or batch job. Model Prices lets you compare DeepSeek against other providers.

Prices come from the open-source LiteLLM catalog and are not verified against provider billing. Check DeepSeek's own pricing page before committing to a budget.
